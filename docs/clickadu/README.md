## 4. Partner Tracking Capability (`request_var`)
Clickadu supports custom sub-source parameters via `request_var`.
When serving ads to visitors referred by partners (e.g. `?ref=partnerA`), we pass `request_var=partnerA` in the ad tag/VAST URL.

The revenue generated by each partner can be queried directly using:
```
http://v2.api.clickadu.com/partner/requestVarStats?token=<API_TOKEN>&dateFrom=YYYY-MM-DD&dateTo=YYYY-MM-DD&format=json
```
